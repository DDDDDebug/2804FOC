FOC 与 STM32 入门

基于本项目：STM32F103C8T6 + AS5600 + SimpleFOCmini + 2804 电机

先记住一句话：
STM32 负责高速重复计算，AS5600 提供转子位置，FOC 根据位置计算三相 PWM，SimpleFOCmini 放大 PWM 去驱动电机。
AS5600
↓ I²C 读取机械角度
STM32 定时器中断
↓ FOC 计算
TIM3 三路 PWM
↓
SimpleFOCmini → 2804 电机

1. STM32 在项目中的角色

启动代码主要在 Core/Src/main.c：

HAL_Init();
SystemClock_Config();

MX_GPIO_Init();
MX_I2C1_Init();
MX_TIM3_Init();
MX_TIM1_Init();

FOC_Init(...);
TIM_Init();
  • GPIO：控制 PB1 使能脚和 LED。
  • I2C1：通过 PB6/PB7 读取 AS5600。
  • TIM3：通过 PA6、PA7、PB0 输出三相 PWM。
  • TIM1：产生固定频率的 FOC 控制中断。

2. AS5600 如何提供角度

代码在 Bsp/Src/angle_as5600.c。STM32 向 AS5600 指定角度寄存器，然后读取两个字节：

HAL_I2C_Mem_Read(
    hi2c, 0x6C, 0x0C,
    I2C_MEMADD_SIZE_8BIT,
    buf, 2, 50
);

本项目中：

  • AS5600 的 7 位地址是 0x36。
  • STM32 HAL 使用左移后的地址，所以代码写成 0x6C。
  • 角度寄存器从 0x0C 开始。
  • AS5600 返回 12 位角度值，范围是 0 到 4095。
angle = raw * (360.0f / 4096.0f);

3. FOC 控制循环

控制调度主要在 Drv/Src/drv_tim.c。TIM1 产生约 20 kHz 中断，程序分频后每约 1 ms 执行一次 Motor_Loop()。

每次控制循环大致是：

读取 AS5600
→ 计算机械角度和速度
→ 计算目标角度误差
→ PID 计算 Uq
→ 计算三相电压
→ 更新 PWM

4. 位置控制怎样工作

核心代码在 App/Src/motor_ctrl.c 和 App/Src/Foc.c：

FOC_PosCtrl(&Motor);
FOC_SpdCtrl(&Motor);
FOC_Output(&Motor);
  1. FOC_PosCtrl()：比较目标角度和当前角度。
  2. FOC_SpdCtrl()：根据速度误差计算需要的力矩电压 Uq。
  3. FOC_Output()：把 Uq 和电角度转换为三相 PWM。

可以先这样理解：

角度误差大 → 需要更快转
速度误差大 → 需要更大 Uq
Uq + 电角度 → 三相 PWM

5. 为什么极对数是 7

你的电机参数是 12N14P：

  • 12 个定子槽。
  • 14 个转子磁极。
  • 极对数 = 14 ÷ 2 = 7。

代码中对应：

.pole_pairs = 7,

机械角度转电角度时：

电角度 = 机械角度 × 7

极对数错误时，常见现象是抖动、嗡嗡响、不转或发热。

6. PWM 与 SimpleFOCmini

PA6 → TIM3_CH1 → IN1
PA7 → TIM3_CH2 → IN2
PB0 → TIM3_CH3 → IN3
PB1 → EN

三路 PWM 经过 SimpleFOCmini 的功率级，形成三相驱动电压。当前项目有安全开关：

#define MOTOR_POWER_STAGE_ENABLED 0U

值为 0 时，PB1 不拉高、PWM 不启动，电机不会被使能。接入合适的 12 V 电源并确认接线后，才考虑改为 1U。

7. 推荐学习顺序

  1. 看懂 MX_I2C1_Init()，知道 PB6/PB7 怎样初始化。
  2. 看懂 AS5600_ReadAngle()，理解一次角度读取。
  3. 看懂 MX_TIM3_Init()，理解 PWM 通道。
  4. 看懂 TIM_Init()，理解控制中断。
  5. 跟踪 Motor_Loop() 的执行顺序。
  6. 最后再学习 Clarke、Park、反 Park 和 SVPWM。
